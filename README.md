# Kosta Gaitanis — Engineering Portfolio

Dependency-free static portfolio site designed for GitHub Pages.

## Structure

- `index.html` — portfolio overview
- `projects/eyemaps.html` — deep engineering / 3D mapping case study
- `projects/crealogix.html` — multi-bank platform and leadership case study
- `projects/bity.html` — fintech / native iOS architecture case study
- `projects/icpkit.html` — open-source protocol / cryptography engineering case study
- `assets/styles.css` — all styling

The upcoming native iOS + AI project appears on the homepage as current work and can become a full case study once it is built.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

The site has no build step. It can be published directly from the repository root with GitHub Pages.

## Before publishing

1. Add preferred public email and LinkedIn URL.

3. Add historical Bity screenshots and simplified architecture diagrams.
4. Confirm the exact CREALOGIX client list against Kosta's employment period and confidentiality constraints.
5. Add measurable outcomes where they are known and defensible.
6. Replace the AI-project placeholder when the new app has a concrete concept/build.
