Case Study · IcpKit

Making a blockchain protocol usable from native Swift.

IcpKit is an open-source Swift package for communicating with the Internet Computer. It provides Swift APIs for Candid and CBOR serialization, identities, request signing and canister calls.

The engineering problem

Without a dedicated library, protocol-level details would leak into every application feature that needed to perform a query, sign a request or call a canister.

IcpKit keeps those details in one place. The package maps Internet Computer concepts into Swift types and APIs while handling serialization, signing and transport underneath.

What the package handles

Candid

Binary serialization and deserialization, Swift Codable integration and parsing of interface definitions.

CBOR

Encoding the protocol structures required to communicate correctly with Internet Computer nodes.

Cryptographic identities

Signing, signature verification and self-authenticating principals for secure requests.

Canister communication

Construction and execution of signed query/update calls while presenting a Swift-native API.

Source generation

Generation of Swift interfaces from Candid definitions to reduce protocol boilerplate and errors.

Ledger support

Higher-level primitives needed by applications that interact with Internet Computer assets and ledgers.

Testing the protocol layer

At the latest measurement, IcpKit had 73% code coverage, entirely through unit tests.

The test suite provides fast, repeatable feedback as the package evolves. Keeping these tests at the unit level makes protocol behavior deterministic and allows failures to be isolated without depending on external services.

Real-world production use

IcpKit is used in the production apps of Bity and Tangem, the company behind the NFC card hardware wallet. These two integrations were developed independently of each other.

Design approach

I wanted application code to work with Swift types rather than serialized protocol structures. IcpKit therefore keeps Candid, CBOR, signing and transport concerns behind a smaller API. The package source and history are public, so the implementation can be inspected directly.

How the project started

I was the main developer of IcpKit. The project was originally developed while I was at Bity SA with support from the DFINITY Foundation Developer Grant Program. The repository is maintained under my GitHub account.
