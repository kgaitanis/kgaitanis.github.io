Case Study · IcpKit

Making a blockchain protocol usable from native Swift.

IcpKit is an open-source Swift package for communicating with the Internet Computer. It provides Swift APIs for Candid and CBOR serialization, identities, request signing and canister calls.

The missing native protocol layer

No comparable native iOS library existed for the Internet Computer. An application otherwise had to implement serialization, identities, request signing, transport and ledger behavior before it could perform even a basic query or transfer.

Without a dedicated library, those protocol details would leak into every feature that needed to read state, sign a request or call a canister.

Key architectural decision: a Swift-native boundary

IcpKit maps Internet Computer concepts into Swift types and APIs while keeping Candid, CBOR, signing and transport behind a smaller interface. Application code works with native types rather than serialized protocol structures.

Protocol and ledger implementation

Candid

Binary serialization and deserialization, Swift Codable integration and parsing of interface definitions.

CBOR

Encoding the protocol structures required to communicate correctly with Internet Computer nodes.

Cryptographic identities

Signing, signature verification and self-authenticating principals for secure requests.

Canister communication

Construction and execution of signed query/update calls while presenting a Swift-native API.

Source generation

Generation of Swift interfaces from Candid definitions to reduce protocol boilerplate and errors.

Ledger support

Read and write support for ICRC-1 tokens, ICRC-2 approvals, ICRC-3 transaction history and ICRC-7 NFTs.

Developer experience

IcpKit's public examples show how an application can read an ICP balance and send ICP or other tokens within minutes, using only a few dozen lines of Swift.

Generated interfaces and Swift-native values keep protocol boilerplate out of application features, allowing developers to focus on product behavior rather than wire formats and request construction.

Testing and production adoption

Unit tests cover approximately 95% of the Swift codebase. The repository-wide figure is 73% because it also includes a separately licensed, externally authored Rust component for signature verification, outside the scope of the Swift test suite.

Unit-level tests make protocol behavior deterministic, provide fast feedback and isolate failures without depending on external services.

IcpKit was independently adopted in the production apps of Bity and Tangem, the company behind the NFC credit card hardware wallet. These integrations demonstrated that the library worked beyond its original product context.

Scope of ownership and project origin

I created IcpKit and remain its principal developer, owning its API design, protocol implementation, code generation, testing and ongoing maintenance. The project began while I was at Bity SA with support from the DFINITY Foundation Developer Grant Program. Its source and history remain publicly inspectable under my GitHub account.
